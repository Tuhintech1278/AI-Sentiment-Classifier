# AI Sentiment Classifier

An AI-powered web application that analyzes user-provided text and determines whether the sentiment is Positive, Negative, or Neutral.

## Features

- User enters their own text
- AI analyzes the text
- Predicts Positive, Negative, or Neutral sentiment
- Simple and attractive web interface
- Machine learning based sentiment classification

## Technologies

- Python
- Flask
- Pandas
- Scikit-learn
- NLTK
- HTML
- CSS
